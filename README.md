
# Higher Education Data Analysis
## College Tuition, Financial Aid & Student Debt

### 📊 Project Overview

This project analyzes higher education data to explore trends in college tuition, financial aid, student loan disbursements, and the cost of attending college.

The project focused on organizing multiple datasets into a PostgreSQL database, using SQL to explore trends and relationships, and preparing summary data for analysis and visualization.

### 🎯 Business Questions

- How do tuition costs compare across different institution types?
- Which states have higher tuition and loan disbursements?
- How is financial aid distributed across different student groups?
- What portion of the total cost of college comes from tuition, housing, food, and other expenses?
- How do tuition and student financial assistance vary across groups?

### 🗂️ Data Sources

The project used publicly available higher education datasets from:

- College Scorecard
- IPEDS / National Center for Education Statistics (NCES)
- Federal Student Aid
- U.S. Census American Community Survey (ACS)

### 🔎 Analysis Process

1. **Data Collection** — Collected publicly available higher education datasets.
2. **Data Preparation** — Cleaned and organized the datasets for analysis.
3. **Database Development** — Created PostgreSQL tables to structure the data.
4. **SQL Analysis** — Used SQL queries to explore trends by state, institution type, and degree.
5. **Data Integration** — Joined tuition, loan, and demographic datasets.
6. **Visualization** — Prepared summary data for analysis and visualization.
7. **Insights & Recommendations** — Interpreted findings to support data-driven decision-making.

### 🗄️ Database Tables

The project included tables for:

- Disbursements by State
- Aid Distribution
- Average Tuition
- College Tuition by State
- Cost Distribution

### 📈 Key Analysis

The analysis examined:

- Grant and loan disbursements
- Grant and loan recipients
- Average grant and loan amounts
- Tuition and fees
- Net price
- Living expenses
- Total college costs
- Tuition differences by institution type
- State-level trends

### 🔐 Data Governance

Data governance was considered throughout the project, including the use of publicly available datasets, protection of sensitive information, verification of data sources and limitations, and consideration of potential bias when comparing demographic groups.

### 💡 Challenges & Problem Solving

One challenge involved importing datasets into PostgreSQL using SQL scripts. Alternative approaches using Excel and Tableau were explored before successfully loading the data into pgAdmin and creating the required SQL tables.

This experience strengthened my ability to troubleshoot data-loading issues, work with different file formats, and adapt my workflow when technical challenges arose.
